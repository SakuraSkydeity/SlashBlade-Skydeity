# 拔刀剑 源流 · SkydeitySlash

**「江晚雪霁冬」**

基于 SlashBlade Resharped 的 Forge 附属模组，为拔刀剑的世界带来全新的命名刀、锻造材料与一个全新维度。

</div>

---

## 特性

**命名刀**

每柄刀拥有独立的拔刀技（SA）、多重附魔特效（SE）、逐字渐变刀名与专属模型贴图。目前已加入：

- 芙宁娜「枫丹」静水流涌之辉、胡桃「璃月」雪霁梅香、奥黛塔「至冬」白湖冬羽
- 伊洛伊「向阳」三十八亿年的海市蜃楼、墨染江湖「离恨烟」、莉奈娅「诺德卡莱」启喻鸟·博闻异旅
- 哥伦比娜「少女」、残虹「赤葵」饲火殷红幻景的暮落残阳
- 中间刀「源流」神原 / 「源流」未竟（无 SA/SE，数值同原版阎魔刀，是高阶刀的锻造材料）

**新维度「彼岸」**

虚空维度：无生物生成、无随机时间刻、死亡不掉落，供特效演示与场景搭建使用。

**「新月台」多方块合成**

八座基座 + 中央核心的锻造系统：先用工作台把练好的无名刀（5200 妖魂 / 520 杀）合成为中间刀「源流」神原或「源流」未竟，再在新月台锻造成上述命名刀。

**丢刀化形**

掷出的爱刀会化作可拾取的人形幻影。幻影打不死，也不会被自己的刀误伤。

**充能条与法环**

八把高阶刀（芙宁娜 / 胡桃 / 奥黛塔 / 莉奈娅 / 哥伦比娜 / 伊洛伊 / 残虹 / 墨染江湖）在物品栏里原版耐久条的位置各有一条**渐变充能条**（支持任意段数色标：芙宁娜、奥黛塔、胡桃、残虹、墨染江湖是手工指定的配色，其余按刀自身主题色自动推）；手持该刀右键一次 +1、共 30 点；**按 Ctrl 可切换条的显示/隐藏**。满值后玩家身后会浮现该刀专属的**法环**（内外两层贴图环、各自反向旋转）：目前**芙宁娜、墨染江湖（樱狐）、残虹**三把已各有自己的环，其余刀还没有。法环固定在背后、跟着身体转动，第三人称视角里芙宁娜与残虹在**右上方**、樱狐在**左上方**。刀一旦**丢下、放进容器、或换了主人**，充能立刻清零。

**墨染江湖（樱狐）的法环是循环播放的**：双环反向自转约 10 秒 → 整组快速放大一圈 → 换成一道斜向的**拉线**纹样，出现在身体正后方（直接出现，无放缩）→ 停留 2 秒 → 回到双环，整轮约 12.6 秒，如此往复。

**独立特效库**

剑技以外的演出特效都做成了可单独调用的实体，方便搭场景与逐帧取景：超位法术（巨型地面法阵 + 天光 + 光柱 + 升腾符文，纯视觉无伤害）、向阳天降打击（瞄准锁定目标的一道光炮：高空引导环 + 瞄准引线 + 落点聚能，锥形紫光柱 + 命中闪光 + 原版紫尘）、翾风回雪环（淡蓝渐变的交错圆环：三段低空轨道弧 + 四层倾斜悬浮环 + 居中的竖弧笼；消散较快）、全息剑（贴图刀落下 → 落地一圈浅蓝光环 + 四周蓝色丝线**弯着**汇聚到剑根，丝线是**几何绘制**、每条起点不同、各带一道弧与波动）、天星法阵、墨狐领域、新月法则（代码画的地面法阵：九颗蓝白十字星）、幽灵蝶等。

**渲染性能优化**

针对拔刀剑的 OBJ 模型渲染做了独立优化：模型在加载时烘焙一次，渲染期直接复用顶点数据，不再每帧重算。剑雨、刀光、剑气这类由刀模绘制的大量特效因此共享同一批数据。附带阴影代理盒与刀光距离降级。不改变画面表现，出现异常会自动退回原版渲染。

## 指令

```
/skydeityslash enter mandarava    进入彼岸
/skydeityslash leave mandarava    返回原世界
/skydeityslash effect <特效>      特效预览：overrank（超位法术）/ tianxing / newmoonrule / ink_fox / chikuiflower / iroibeam（向阳·斜光轰击）
/skydeityslash preview <组> <编号> 子特效逐个预览：naru 0-5 / enlight 0-8
```

## 前置与安装

需要 **Minecraft 1.20.1** 与 **Forge 47.4.10+**，并以 **SlashBlade Resharped 1.9.x** 为运行基础。**JEI / EMI** 为可选组件，用于配方查询。

## 从源码构建

使用 **JDK 21** 与项目自带的 Gradle Wrapper：

```powershell
.\gradlew.bat build -x test
```

产物位于 `build/libs/SlashBlade Skydeity-1.0.0.jar`。
